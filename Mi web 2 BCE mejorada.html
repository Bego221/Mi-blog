Mi primera página web

Escrito por Begoña Castaño Espejo

Durante el curso hemos aprendido a crear una página web utilizando HTML. Hemos conocido diferentes etiquetas para escribir y organizar textos, poner palabras en negrita, cursiva y subrayadas, cambiar el tamaño y el color de las letras y crear títulos y subtítulos. También hemos aprendido a insertar imágenes, añadir enlaces a otras páginas web, crear listas ordenadas y separar los textos en párrafos. Además, hemos aprendido a alinear textos, utilizar saltos de línea y organizar los diferentes elementos para que la página quede más ordenada y bonita. Gracias a los vídeos del curso, hemos aprendido cómo funcionan las etiquetas HTML, cómo se escriben y cómo se utilizan para diseñar nuestra propia página web desde cero.

Escrito por Begoña Castaño Espejo
